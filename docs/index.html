What is HawkClient?

HawkClient - A developer and git friendly offline only API client designed for efficient API testing and development. Test, debug, and manage APIs efficiently with a free Postman/Insomnia alternative.

Team Collaboration

HawkClient stores the API requests and collections in .yaml files. Theses files can be shared with team using any version control system like git.

Privacy

HawkClient does not require any sign up or sign in nor it collects any user data. HawkClient focuses on offline only approach making it secure and relaible API testing tool.
