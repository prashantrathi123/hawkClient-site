FAQs

What is HawkClient?

HawkClient is an offline-only API testing tool designed for developers to test, debug, and collaborate on API requests without requiring an internet connection.

How does team collaboration work with HawkClient?

Team collaboration with HawkClient is done through GitHub. Users can share collections and changes via version control, enabling smooth collaboration.

Privacy and Security

HawkClient is an offline-only app. It does not collect any user data nor require any sign-in, ensuring maximum privacy and security.

Does HawkClient require an account or login?

No, HawkClient is completely offline and does not require any login or cloud-based accounts.

Does HawkClient support GraphQL APIs?

Yes, HawkClient fully supports REST and GraphQL API requests.

Does HawkClient support gRPC?

Yes, HawkClient supports gRPC requests.

Does HawkClient support websocket?

Yes, HawkClient supports websocket requests.
